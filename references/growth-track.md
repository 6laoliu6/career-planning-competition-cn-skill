# 成长赛道指导

## 评审核心

成长赛道评的是已经发生并持续迭代的成长过程，不是未来愿望的华丽程度。最有说服力的结构是：

职业目标形成依据 → 目标岗位要求 → 当前差距 → 针对性行动 → 阶段成果 → 反思复盘 → 路径调整 → 下一阶段行动。

## 评分映射

### 一、职业目标（官方30分）

应同时回答五个问题：

1. 为什么该职业对国家战略、区域发展、行业或具体人群有价值？
2. 该行业和岗位真实存在什么需求、任务和发展趋势？
3. 目标为什么与专业学习、个人优势、兴趣和经历匹配？
4. 目标岗位要求哪些专业能力与综合素质？
5. 自己还缺什么，准备如何补足？

有效证据包括官方产业数据、权威行业报告、真实招聘信息、从业者访谈、课程与专业培养方案、职业体验、测评的辅助信息。测评只能作为旁证，不能代替真实体验和能力证据。

目标宜具体到“服务场景＋职业角色＋价值”，例如“面向县域基层医疗场景的医学检验技术人员”，比“成为优秀医务工作者”更可评估。目标可以保留合理弹性，但不能在报告、PPT和答辩中反复变化。

### 二、学习实践行动（官方50分）

这是最高权重。每项行动用以下证据链表达：

| 要素 | 要回答的问题 |
|---|---|
| 目标要求 | 这项行动针对岗位哪项能力？ |
| 具体行动 | 何时、何地、持续多久、承担什么任务？ |
| 过程产出 | 完成了什么作品、项目、报告、服务或训练？ |
| 结果成效 | 有什么可量化变化、第三方评价或阶段成果？ |
| 能力变化 | 与行动前相比，哪项能力得到怎样的提升？ |
| 证明位置 | 证书、作品截图、数据、评价或链接在哪里？ |

优先呈现与目标紧密相关的2—4组代表性行动，不把所有奖项和活动罗列成流水账。证据强度通常为：真实场景解决问题与成果验证 > 长期项目或实践 > 有评价的作品 > 竞赛与证书 > 课程学习 > 仅有计划。

成果描述应包含可验证对象和作用，例如“负责问卷设计并分析328份有效样本，结论被团队用于调整服务流程”，比“提升了数据分析能力”更有力。数字必须真实并能解释口径。

### 三、优化改进（官方20分）

至少呈现一次完整调整闭环：

1. 原计划或原认识是什么；
2. 在学习实践中发现了什么问题；
3. 用什么反馈或数据判断问题；
4. 分析问题原因；
5. 对职业目标、阶段路径或行动方式做了什么调整；
6. 调整后出现了什么变化；
7. 下一次复盘节点和判断标准是什么。

调整不等于频繁换目标。可以保持职业方向稳定，调整能力培养顺序、实践场景、方法或里程碑。承认不足时必须给出改进动作和验证方式。

## 内部诊断量表（非官方分值）

在官方三个维度内，用四档判断证据成熟度：

- A：主张具体，证据可核验，行动与岗位要求直接对应，并有结果与反思。
- B：逻辑完整且有证据，但成果深度、量化或外部验证不足。
- C：有经历和计划，关联性弱，主要依赖自述或证书罗列。
- D：主要是口号、测评结果和未来计划，缺少已发生的行动。

内部诊断只能帮助确定修改优先级，最终估分仍按官方30/50/20计算。

## 常见失分点

- 用宏大政策开场，却没有说明个人行动怎样回应实际需求。
- 职业目标过宽，岗位任务和能力要求不清楚。
- “我喜欢、我适合”没有经历、反馈或作品支持。
- 计划篇幅大于行动成果，像规划书而不是成长记录。
- 奖项很多但与目标职业无关，无法证明能力增长。
- 只写成功，不写问题、原因和调整，丢失优化改进分。
- 报告、PPT与答辩中的目标名称、数据或时间线不一致。

## 推荐产出顺序

1. 职业目标依据表。
2. 目标岗位能力模型与个人差距表。
3. 学习实践证据清单。
4. 成长时间轴和至少一次调整闭环。
5. 生涯发展报告。
6. 展示PPT与陈述稿。
7. 模拟答辩和评分复盘。
